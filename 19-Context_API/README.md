## 📝 What is Context API?

Context API is a React feature that allows you to share state across the entire app (or part of it) without passing props down manually at every level. It's useful for:

- Theme management (dark/light mode)
- User authentication state
- Language/localization settings
- Shopping cart data
- Any global state that multiple components need

## 🎯 Project Goals

This project will demonstrate:

- Creating a Context
- Providing context values
- Consuming context with useContext hook
- Best practices for Context API usage
- Performance optimization techniques
