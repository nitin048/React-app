# React Learning Projects

A collection of React projects built while learning React fundamentals, hooks, and state management.

## 📚 Projects

### 07-Functions

Learning React component functions and basic component structure.

### 08-useState

Introduction to React's `useState` hook for managing component state.

### 09-useState-Adv

Advanced `useState` patterns and techniques.

### 10-form-handling

Handling forms in React with controlled components.

### 11-two_way_binding

Two-way data binding patterns in React.

### 12-Notes_App

A complete notes application with add and delete functionality.

- Add notes with title and details
- Display notes in a card layout
- Delete individual notes

### ui_project

UI components and page layouts practice.

## 🚀 Getting Started

Each project is independent. To run any project:

```bash
cd [project-name]
npm install
npm run dev
```

## 🛠️ Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- ESLint
